# PP2 Tracker

🇬🇧 **English:** the counter has an English user interface, and the English guide is at the [bottom of this page](#english).

Pro Pilkki 2 -pelin pelinaikainen paino- ja kappalelaskuri. Näyttää
kisatyypin mukaisen tuloksen kalastaessa, koska peli ei itse näytä sitä.
Toimii työpöytä- ja Microsoft Storen versiolla.

## ⬇️ Lataa uusin versio / Download the latest version

**[PP2-Tracker-asennus.exe](https://github.com/nousiainenlassi-afk/pp2-tracker-lataus/releases/latest/download/PP2-Tracker-asennus.exe)**

Linkki lataa aina uusimman version. Muutokset näkyvät
[julkaisusivulla](https://github.com/nousiainenlassi-afk/pp2-tracker-lataus/releases/latest).

## Asennus ja päivitys

1. Lataa ja aja asennusohjelma.
2. Jos koneella on jo aiempi versio, valitse **Päivitä** (asetukset
   säilyvät) tai **Puhdas asennus**.
3. Lopuksi aukeaa LUEMINUT, jossa on uudet ominaisuudet ja ohjeet.

Versiosta 2.0.6 alkaen laskuri kertoo itse, kun uusi versio on
saatavilla. Paina **Päivitä nyt**, niin laskuri päivittyy ja käynnistyy
uudelleen – asetukset säilyvät.

Mitään muuta ei tarvitse asentaa, eikä järjestelmänvalvojan oikeuksia
tarvita. Jos Windows näyttää "Windows suojasi tietokoneesi":
**Lisätietoja → Suorita joka tapauksessa**.

## Käyttö

1. Käynnistä Pro Pilkki 2 ikkunoituna (Koko näyttö = Ei, Ikkunoitu täyskuva = Kyllä).
2. Käynnistä PP2 Tracker työpöydän kuvakkeesta.
3. Pelaa. Kisatyyppi, kisan alku ja jokainen nosto tunnistetaan itse.

Laskurin käyttöliittymä on myös englanniksi: Asetukset → Perusasetukset →
*Kieli / Language* (muutos tulee voimaan uudelleenkäynnistyksessä).
Oletuskieli seuraa Windowsin kieltä.

## English

**PP2 Tracker** is a live weight and fish counter for Pro Pilkki 2. It
shows your contest score while you fish, because the game itself does
not. It works with both the desktop and the Microsoft Store version of
the game, in Finnish or English.

### ⬇️ Download the latest version

**[PP2-Tracker-asennus.exe](https://github.com/nousiainenlassi-afk/pp2-tracker-lataus/releases/latest/download/PP2-Tracker-asennus.exe)**

The link always downloads the newest version. Changes are listed on the
[release page](https://github.com/nousiainenlassi-afk/pp2-tracker-lataus/releases/latest)
(English notes are in the collapsible "English" section).

### Language

The counter has an English user interface. Choose it in
Settings → General → *Kieli / Language*; the change takes effect when you
restart the counter. By default the language follows Windows. An English
guide, `README.txt`, is installed next to the program.

### Install and update

1. Download and run the installer.
2. If an earlier version is installed, choose **Update** (settings are
   kept) or **Clean install**.
3. No administrator rights are needed. If Windows shows "Windows
   protected your PC": **More info → Run anyway**.

The counter tells you by itself when a new version is available: press
**Update now** and it updates and restarts. Settings are kept.

### Use

1. Start Pro Pilkki 2 in windowed mode (Full screen = No, Windowed full
   screen = Yes).
2. Start PP2 Tracker from the desktop icon.
3. Play. The contest type, the start of a contest and every catch are
   detected automatically.
