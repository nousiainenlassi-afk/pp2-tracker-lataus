# PP2 Tracker

Pro Pilkki 2 -pelin pelinaikainen paino- ja kappalelaskuri. Näyttää
kisatyypin mukaisen tuloksen kalastaessa, koska peli ei itse näytä sitä.
Toimii työpöytä- ja Microsoft Storen versiolla.

## ⬇️ Lataa uusin versio

**[PP2-Tracker-asennus.exe](https://github.com/nousiainenlassi-afk/pp2-tracker-lataus/releases/latest/download/PP2-Tracker-asennus.exe)**

Linkki lataa aina uusimman version. Muutokset näkyvät
[julkaisusivulla](https://github.com/nousiainenlassi-afk/pp2-tracker-lataus/releases/latest).

## Asennus ja päivitys

1. Lataa ja aja asennusohjelma.
2. Jos koneella on jo aiempi versio, valitse **Päivitä** (asetukset
   säilyvät) tai **Puhdas asennus**.
3. Lopuksi aukeaa LUEMINUT, jossa on uudet ominaisuudet ja ohjeet.

Mitään muuta ei tarvitse asentaa, eikä järjestelmänvalvojan oikeuksia
tarvita. Jos Windows näyttää "Windows suojasi tietokoneesi":
**Lisätietoja → Suorita joka tapauksessa**.

## Käyttö

1. Käynnistä Pro Pilkki 2 ikkunoituna (Koko näyttö = Ei, Ikkunoitu täyskuva = Kyllä).
2. Käynnistä PP2 Tracker työpöydän kuvakkeesta.
3. Pelaa. Kisatyyppi, kisan alku ja jokainen nosto tunnistetaan itse.
